# 工厂碳数据护照 P0 产品规格

## 一句话产品定义

工厂碳数据护照不是一份报告，而是一个稳定的生产装置账户：它把不可变的身份、工艺、产品、期间、产量、活动排放、证据、规则、确定性结果、方法学复核和共享记录组织成可重放的版本。

## 本轮成品边界

```text
创建装置账户
→ 建立装置 / 工序 / 产品正式事实
→ 接入已确认活动数据与证据
→ 登记期间产量并完成排放归集
→ 生成确定性 SEE
→ 派生档案完整度
→ 生成冻结草稿
→ 方法学复核（非正式法定核查）
→ 发布不可变版本
→ 创建限范围共享授权
→ 导出或跨租户读取脱敏核验包
→ 撤销后立即停止访问
```

## 第一性原理

1. 护照的价值来自降低可辩护签名成本，不来自页面数量。
2. 报告是档案的投影；正式事实不能从报告 DTO 反向写入。
3. AI 只能帮助提取、发现缺口、解释和起草；发布资格由确定性谓词决定。
4. 共享的最小权限单位是“某个发布版本 × 某个接收方 × 某个目的 × 某组字段 × 某段有效期”。
5. “方法学复核通过”不等于“法定核查通过”，界面和数据模型必须始终保留此差异。

## 九项发布检查

1. 装置身份完整；
2. 至少一个正式生产工序；
3. 至少一个有效八位 CN 产品；
4. 报告期间存在正数吨产量；
5. 活动排放已完整归集到工序；
6. 正式排放引用真实源文件证据；
7. SEE 结果可由历史记录重放，并覆盖冻结时仍有效的全部产量与归集版本；
8. 方法学规则为同租户、有权角色登记、approved 且覆盖期间的 RuleRecord；
9. 存在针对同一冻结草稿的方法学复核通过记录。

任何一项失败都禁止发布，客户端不得覆盖检查结果。
冻结后若产量、归集或排放结果发生正式修订，旧草稿及其复核立即失去发布资格；必须重新冻结、重算 SEE 并重新复核。已经发布的历史版本保持不可变，不会被后续修订改写。

## 明确不做

- 不声称完成欧盟法定核查或申报；
- 不生成绿证、交易、抵扣资格或金融建议；
- 不开放持有链接即可访问的长期秘密 URL；
- 演示租户可以走完整账本路径，但所有合成数据必须显式标注，且不得冒充真实监管事实；
- 不新增第二套 Evidence 或第二本排放账本。

## 当前证据边界

P0 保存 RuleRecord 的发布方、文号、适用期、HTTPS 来源和人工核对后的原文 SHA-256，并使该记录不可改写。平台当前不会自动下载法规原文并重新计算该哈希，因此“规则已登记”只能证明登记与版本治理已经发生，不能证明法规内容已被平台独立认证。
