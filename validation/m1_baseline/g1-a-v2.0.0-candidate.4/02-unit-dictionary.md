| 属性 | 值 |
|---|---|
| 规则 ID | `G1A2-UNIT-001` |
| 版本 | `G1-A-v2.0.0-candidate.4` |

| 依据 | `bcd5...` 固定外购电单位并要求补记其余单位；`f92d...` 记录 `t/kWh/tCO2e/tCO2e/t`；`c30...` 授权单位归一 |

## 规范单位

| 单位代码 | 中文含义 | 语义量纲 | 相对量纲基准的精确比例 | 允许位置 |
|---|---|---|---|---|
| `t` | 吨产品 | `PRODUCT_MASS` | `1000/1` 相对 kg | `production_output` |
| `kWh` | 千瓦时 | `ENERGY` | `3600000/1` 相对 J | `purchased_electricity` 及因子分母 |
| `kgCO2e` | 千克二氧化碳当量 | `EMISSION_CO2E` | `1/1` | 因子分子和计算中间量 |
| `tCO2e` | 吨二氧化碳当量 | `EMISSION_CO2E` | `1000/1` 相对 kgCO2e | 排放结果 |
| `kgCO2e/kWh` | 每千瓦时千克二氧化碳当量 | `EMISSION_CO2E / ENERGY` | 由结构化分子/分母精确组成 | 外购电因子 |
| `tCO2e/t` | 每吨产品吨二氧化碳当量 | `EMISSION_CO2E / PRODUCT_MASS` | 由结构化分子/分母精确组成 | 排放强度 |

`PRODUCT_MASS` 与通用质量在本规则中保持业务语义区分，避免把其他质量流误作合格产量。`EMISSION_CO2E` 也不得仅按物理质量与 `kg` 混用。

## 输入与换算

1. 两个正式核心活动字段的固定输入单位只有 `t` 和 `kWh`；本版不接受 `kg`、`MWh`、`万kWh`、`吨`、大小写变体或 OCR 字形作为正式字段单位。
2. 来源文档若出现非规范单位，候选必须标记 `ambiguous` 或进入 `EXC-UNIT-001`；不得由 AI 或字符串相似度自动换算。
3. 唯一结果换算为 `1000 kgCO2e = 1 tCO2e`，使用精确有理数 `1/1000`，不产生舍入。
4. 复合单位按结构化组件判定：活动 `kWh^1` × 因子 `kgCO2e^1·kWh^-1` 必须完全约消为 `kgCO2e^1`；残留任何维度即阻断。
5. 单位代码大小写敏感；原始字符串只用于显示，计算使用固定代码及版本。

## 精度

单位换算使用 Decimal/整数比例，工作精度至少 50 位且禁止二进制 float；换算过程中不舍入。只在最终 `tCO2e` 或 `tCO2e/t` 结果边界执行 `HALF_UP` 6 位量化。

## 确定性测试

- `T-UNIT-01`：`2,000,000 kWh × 0.500000 kgCO2e/kWh = 1,000,000 kgCO2e = 1000.000000 tCO2e`。
- `T-UNIT-02`：`kgCO2e/kWh` 与 `kWh` 完全约消；`kgCO2e/kg` 与 `kWh` 不兼容并阻断。
- `T-UNIT-03`：`MWh`、`KWH`、`吨` 进入正式字段均失败，不自动转换。
- `T-UNIT-04`：所有 39 个现有场景的 extracted 产量/用电单位分别为 `t/kWh`。

## 差异结论

相对批准语义不改变活动或结果单位；相对 quantity 代码支持的更大单位集合，本候选刻意只冻结本次最小业务闭环所需单位，不把通用代码能力扩大成业务许可。
