## 计算前置门

只有下列条件全部满足时才计算：9/9 当前字段版本有效人工确认；字段证据为 `SUPPORTED`；单位、期间、边界和因子版本精确匹配；无开放阻断异常。失败只产生验证/异常记录，不得产生排放结果或以 0 代替缺失值。

## 公式与运算顺序

设：

- `A` = 经确认的 `purchased_electricity`，单位 `kWh`；
- `EF` = 唯一适用因子 `0.500000 kgCO2e/kWh`；
- `P` = 经确认且大于 0 的 `production_output`，单位 `t`。

固定顺序：

```text
E_kgCO2e = A_kWh × EF_kgCO2e_per_kWh
E_tCO2e_raw = E_kgCO2e ÷ 1000
E_tCO2e = quantize(E_tCO2e_raw, 0.000001, ROUND_HALF_UP)
I_raw = E_tCO2e_raw ÷ P_t
I_tCO2e_per_t = quantize(I_raw, 0.000001, ROUND_HALF_UP)
```

强度是同一场景/产品/期间的派生指标，不扩大排放边界；不得用已舍入的 `E_tCO2e` 计算强度。若不输出强度，排放总量公式仍独立有效。

## 数值规则

1. 输入运输类型为规范十进制字符串，最大精度 28、最大小数位 12；拒绝 float、NaN、Infinity 和指数溢出。
2. 工作上下文至少 50 位十进制精度；本公式中的乘除使用十进制精确数，不做中间舍入。
3. 最终排放量和强度均固定 6 位小数、`ROUND_HALF_UP`；负零规范为 `0.000000`。
4. 不在单行、单文档或单位换算阶段提前量化；每个最终指标只量化一次。
5. 结果必须记录输入字段版本/hash、证据引用、确认事件、因子 ID/版本、单位字典版本、期间、边界和规则版本，以支持相同输入产生唯一结果。

## 确定性测试

| 测试 | 输入 | 预期 |
|---|---|---|
| `T-CALC-01` | `A=2000000`, `P=1000` | `E=1000.000000 tCO2e`；`I=1.000000 tCO2e/t` |
| `T-CALC-02` | `A=2469.135`, `P=1` | raw `E=1.2345675`；HALF_UP 后 `1.234568` |
| `T-CALC-03` | `A=0`, `P=1000` | `E=0.000000`；`I=0.000000`；0 不等于缺失 |
| `T-CALC-04` | `A=-1` | `EXC-RANGE-001`，不生成结果 |
| `T-CALC-05` | `P=0` | `EXC-RANGE-001`，排放结果/强度均不生成，因为 9 字段完整门失败 |
| `T-CALC-06` | 任一字段 UNCONFIRMED | `EXC-CONFIRM-001`，不生成结果 |

39 个现有合成场景的外购电真值按上述公式重新量化到 6 位必须全部一致；同时单独断言观察基线为 `32 raw exact + 7 legacy +1E-47 tail`，不隐藏已知尾差。这项回归只验证六位结果等价性，不生成或修改 truth。

## 差异结论

公式类型、因子值、排放源和结果含义未变化。代码工作上下文的 HALF_EVEN/12 位存储与本方法最终 HALF_UP/6 位是显式实施差异；现有 7 条 `+1E-47` 尾差在六位量化后消失，因此本候选不改变现有六位结果，但运行时接入前仍须实现并测试最终量化点。
