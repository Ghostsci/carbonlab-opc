# Competition Batch V2 用户测试指南

> 数据均为合成数据，仅用于产品演示，不得用于申报、核查、报价或业务决策。

## 1. 打开系统并取得数据

1. 打开 `http://127.0.0.1:15173/upload`。
2. 如未登录，使用本机已创建的演示账号登录；演示密码由本机环境提供，仓库不保存密码。
3. 点击页面中的“下载50行明细版（12个Excel）”，或使用本地压缩包：
   `/Users/Ghost/Downloads/CarbonLab_12个Excel_每个50条明细_V2.zip`。
4. 解压后先选择 `DEMO_ONLY_202601_HR_50rows.xlsx`。

## 2. 按工作流操作

1. 点击“上传文件”，选择上述工作簿。
2. 核对识别结果：
   - 期间：`2026-01-01 至 2026-01-31`
   - 用电量：`2480000 kWh`
   - 设施：`一号热轧生产装置（合成）`
   - 金额：`1780640 元`
3. 点击“A-03 运行证据质检”。预期：质检通过，可带人工提示，但阻断项为 0。
4. 点击“H-01 人工确认并写入正式账本”。预期：生成 ActivityData ID。
5. 在 H-02 选择“演示电力因子（非监管用途）”，因子值应为 `0.5 kgCO2e/kWh`。
6. 点击“H-02 确认因子并运行 R-01”。
7. 预期正式结果：`1,240 tCO2e`。

计算关系：

```text
2,480,000 kWh × 0.5 kgCO2e/kWh ÷ 1,000 = 1,240 tCO2e
```

## 3. 检查 50 条明细

打开工作簿第二个工作表“50条用电明细”：

- 必须恰好有 50 条数据行；
- 每行结束读数应不小于起始读数；
- 50 条“用电量(kWh)”合计应为 `2,480,000`；
- 合计必须与“账单摘要”的本期用电量一致。

## 4. 测试其他文件

其余 11 个工作簿可重复同样步骤。每次只上传一个文件；当前版本尚未提供多文件并行上传。

若 H-02 显示“未找到同年份、同区域兼容的正式因子”，请先在当前代码版本重新运行合成演示数据初始化命令；系统不会为了让演示通过而自动套用错误年份或错误区域的因子。
