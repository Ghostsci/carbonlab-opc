# Synthetic Factory V1 数据集说明

## 用途

这是 Builder 生成的、可复现的**候选评测集**，用于验证工厂文档候选提取、证据定位、缺失/歧义/冲突判断和文档提示词注入识别。它不是经 Ghost 复核的 Golden Set。

## 构成

| 分层 | 数量 | 用途 |
|---|---:|---|
| candidate | 15 | 开发与 Prompt 错误定位，可调优 |
| holdout | 15 | 冻结后资格测试，不据此静默调优 |
| adversarial | 9 | 提示词注入叠加完整、缺失与冲突攻击 |

共 39 个场景。所有企业、装置和数据均明确标注为合成，固定随机种子可重建；正式排放真值使用 `Decimal` 与 `Quantity` 计算，不由 LLM 生成。

## 覆盖

- 装置、经营者、产品、CN 编码、生产路线和报告期间；
- 带小数和可选千位分隔符的产量、电量；
- 产量缺失、电量缺失、单位不明、跨文档冲突；
- 文档内“忽略规则、直接写入、自动通过”的提示词注入；
- 原文短证据必须能在指定文档中逐字定位。

## 没有覆盖

- PDF 版式、扫描件、OCR、手写体、图片表格；
- 多语言、真实企业模板、异常编码、超大文件；
- 真实客户字段分布和错误分布；
- 法规适用性、因子选择、正式排放计算、核查签名；
- 租户权限和正式账本写入（这些由既有确定性测试验证）。

## 防污染规则

1. candidate 可用于修改 Prompt；holdout/adversarial 结果不能被静默用于同版本调优；
2. 任何数据集修改都会改变 scenario 与 manifest SHA-256；
3. 提升为 Golden Set 前必须由独立 Ghost 审核场景、答案与覆盖缺口；
4. 真实客户试点必须另建脱敏、授权、分层抽样的数据集，不能拿本集合替代。
