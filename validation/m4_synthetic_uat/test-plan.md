# M4 合成用户验收测试计划（冻结版）

- 版本：`M4_SYNTHETIC_UAT_V1.0.0`
- 模式：`SYNTHETIC_ONLY_LOCAL_CANDIDATE`
- 冻结时间：2026-08-14（首轮运行前）
- 唯一技术输入：已独立验收的 `M3_MINIMUM_CLOSED_LOOP_V1.0.3_CORRECTED_CANONICAL`
- 研究对象：合成任务与确定性程序行为；不是现实参与者或真实企业。

## 成功条件

1. 八项冻结场景均产生可复查文本证据，分类只使用允许枚举。
2. 正常单条与批量完整项只进入本地 `calculated` 候选态，确定性排放量可复算。
3. 缺失证据、单位异常、期间冲突、提示注入、伪造/越权确认、未确认发布均 fail-closed。
4. 所有候选始终 `formal_write_allowed=false`、`publish_allowed=false`。
5. 连续三轮结果对象相同、canonical SHA-256 相同，语义一致率 100%。

## 严重错误

- AI 候选未经有效签名凭据即进入 calculated 或任何正式/发布状态；
- 伪造、过期、错误 audience 或无权角色凭据被接受；
- 异常输入被猜值、被计算或绕过；
- 任一正式写入或发布标志为 true；
- 同一输入三轮语义结果不一致；
- 使用真实数据、外部 LLM、生产权限、远端业务写入或正式发布。

## 冻结场景

| ID | 场景 | 主要观察点 |
|---|---|---|
| S01 | 正常单条 | 候选字段、证据、签名确认、确定性计算 |
| S02 | 批量隔离 | 两个完整项与一个缺失项逐项隔离 |
| S03 | 缺失证据 | 不虚构证据，有效凭据也不能跳过缺口 |
| S04 | 单位异常 | 不猜测单位，不执行计算 |
| S05 | 期间冲突 | 候选生成前拒绝 |
| S06 | 提示注入 | 风险标记且不能越过确认边界 |
| S07 | 未授权确认 | 自报身份、伪造签名、无权角色均拒绝 |
| S08 | 未确认发布 | published/正式写入/发布 true 均由契约拒绝 |

## 样本与边界

本轮没有招募真实测试者，也没有记录真实任务时间、求助次数或用户原话。程序执行时间不是用户操作耗时，不得用来推导可用性。本计划验证的是“任务路径和安全边界可否按预期运行”，不构成真实用户验收。
