# 限制矩阵

| 项目 | 分类 | 事实边界 |
|---|---|---|
| 八项合成场景本地重放 | `PASS` | 仅静态 provider 与合成文档；三轮语义一致率 100% |
| 真实非专业用户测试 | `NOT_RUN_ENV` | 未招募、未观察，不产生用户完成率/耗时/求助数据 |
| 真实企业文件与产业场景 | `NOT_RUN_ENV` | 未获授权且不在本任务范围 |
| 外部 LLM | `NOT_RUN_ENV` | 未调用；不能由本轮取得外部模型资格结论 |
| 生产认证签发端点 | `NOT_RUN_ENV` | 仅验证本地签名凭据消费边界 |
| Docker、实时数据库和迁移 | `NOT_RUN_ENV` | 不把 M3 已记录的环境限制改写为 PASS |
| 正式账本写入 | `NOT_RUN_ENV` | `formal_write_allowed=false`，没有远端业务写入 |
| 正式护照发布 | `NOT_RUN_ENV` | `publish_allowed=false`，没有发布动作 |
| 赛事提交 | `NOT_RUN_ENV` | 本附件只是 Issue 内候选证据，不是赛事提交 |

对外边界：已完成工程正确性、模型候选质量和基础可用性验证，尚未完成真实企业产业场景验证。
