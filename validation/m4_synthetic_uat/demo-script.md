# 本地候选演示脚本

1. 明示开场边界：“以下均为合成数据和本地候选，不是正式护照、真实企业试点或监管申报。”
2. 展示 S01：从合成文件到候选字段和字段级证据，再用签名的合成凭据确认，查看冻结规则计算回执。
3. 指出确认后的对象仍是 `calculated_local_candidate`，两个权限标志均为 false。
4. 展示 S02：批量中完整项继续计算，缺失项单独拒绝。
5. 展示 S03—S06：依次查看缺失、单位异常、期间冲突和提示注入的 fail-closed 证据。
6. 展示 S07：调用方自报身份、伪造签名和无权角色均不能产生确认记录。
7. 展示 S08：未确认候选无法改成 published，正式写入和发布 true 被契约拒绝。
8. 展示三轮 replay summary 和相同的 canonical SHA-256。
9. 结束时重申：“已完成工程正确性、模型候选质量和基础可用性验证，尚未完成真实企业产业场景验证。”
