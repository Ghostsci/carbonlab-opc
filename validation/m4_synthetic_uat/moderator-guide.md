# 合成验收主持指南

本指南用于统一重放合成场景，不用于声称已主持真实用户测试。

1. 运行前固定 V1.0.3 输入归档、附件 SHA-256、八项任务说明和成功条件。
2. 只向场景执行器提供产品内可见的合成文件和操作步骤，不注入 truth/expected 字段。
3. 不在执行过程中改写输入、放宽断言、删除失败或手工修复输出。
4. 遇到异常时保留原始拒绝原因、候选状态和字段证据；不得解释成用户能力不足。
5. 每轮独立启动进程，生成逐场景 JSON 与原始日志。
6. 三轮完成后仅按 canonical 对象比较语义，不以日志顺序或展示格式代替。
7. 事实观察、预期拒绝和研究判断分开记录；所有现实用户指标维持“未执行”。
