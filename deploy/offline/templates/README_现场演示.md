# 零碳云现场离线演示包

> DEMO ONLY：包内全部数据与账号仅用于比赛演示，不可用于监管申报、真实客户交付或生产部署。

## 1. 演示电脑前置条件

- Mac 版：Apple Silicon Mac，已安装 Docker Desktop。
- Windows 版：Windows 10/11 x64，已安装 Docker Desktop，并启用 WSL2 Linux 容器。
- Docker Desktop 必须在联网准备阶段安装完成；本包不包含 Docker Desktop 安装程序。
- 现场运行核心闭环不需要网络，也不需要任何大模型 API Key。

## 2. 一键启动

### Mac

双击 `1_START_CARBONLAB.command`。首次运行会导入离线镜像，通常需要数分钟；后续启动更快。

### Windows

双击 `1_START_CARBONLAB.bat`。如系统询问是否允许 PowerShell 运行本地脚本，请允许。

启动完成后浏览器会打开 `http://127.0.0.1:15173/login`，点击 **一键进入演示**。

## 3. 五分钟最短演示路径

1. 一键进入演示，打开“数字化员工工作台”。
2. 上传 `sample-data/DEMO_ONLY_202601_HR_1000rows.xlsx`。
3. 展示“数据标准化入库”：原始字段被映射为 `electricity_kwh`、`period`、`facility`，同时保留 `账单摘要!E5/D5/B5` 等原始位置。
4. 展示 A-03 证据质检；说明 **100 分是自动检查覆盖得分，不等于事实准确率**。若有风险，由 H-01 定位原文、修改或确认保留，未处置风险不能入账。
5. 展示“查看技术详情”中的本体版本、文件指纹、RAG Trace 与 ActivityData 正式记录。
6. 点击“查看已入库的标准化数据”，展示可搜索、可追溯、可导出的标准化数据台账。
7. 展示 R-01 确定性计算与工厂碳数据护照中的原文件、活动数据、排放因子、计算结果、人工确认和操作记录。

## 4. 停止与排障

- 正常停止：双击 `2_STOP_CARBONLAB`。
- 现场检查：双击 `3_CHECK_CARBONLAB`，诊断结果写入 `diagnostics/`。
- 停止不会删除数据。需要彻底重置时，由技术人员执行 `docker compose down -v`。

## 5. 现场失败时的切换顺序

1. 先运行诊断脚本，最多排查 2 分钟。
2. 仍不能恢复时，切换到 `backup/screenshots/` 中的关键截图。
3. 演示视频为独立交付文件，不放入本轻量包；可从赛事平台或演示 U 盘单独播放。
4. 继续讲清“AI 提议—人确认—规则计算—全程留痕”，不要把离线故障描述成业务结果失败。

## 6. 已知边界

- 支持结构化 Excel、CSV 与带文字层 PDF；扫描图片离线 OCR 尚未纳入本演示。
- 1000 行 Excel 已验证关键字段提取与证据质检；当前不宣称可对任意一条明细进行全量语义问答。
- AI 自由问答和外部大模型属于联网增强能力，不影响核心离线演示。

## 7. 本版新增的人机复核闭环

- A-03 每条发现都携带来源位置、观察值、预期值和建议动作。
- Excel/CSV 可显示工作表、单元格与表头；文本/PDF 可显示行号与上下文摘录。
- H-01 必须逐条处置警告并填写理由，处置记录会进入审计链。
- 本轻量离线版的 Git 提交与回滚标签见根目录 `BUILD_INFO.json`。

## 8. 数据标准化如何讲

> 系统不是要求客户先统一表格，而是保留原始文件，再把不同名称翻译成统一碳数据语义。AI 提议字段映射，本体约束业务含义，规则检查单位与期间，人工确认后才写入正式账本。

当前演示验证电费账单最小切口；SAP、ERP、MES 的正式接入需按客户系统配置连接器，不宣称任意系统零配置自动接入。

## 10. 为什么包体明显变小

- 前端已编译为静态文件，由后端同一容器提供，不再携带 Node.js、npm 与前端开发依赖。
- 后端只保留离线演示实际使用的 Python 运行依赖，不携带编译工具与未启用的中间件客户端。
- 数据库使用带 `vector` 与 `pgcrypto` 的 PostgreSQL 16 精简运行镜像。
- 视频不在本包内，避免重复占用约 100 MB；核心离线流程与数据未被删减。


## 9. 标准化数据台账

- 页面入口：左侧导航“标准化数据台账”，或上传页“查看已入库的标准化数据”。
- 客户可查看正式活动数据、原始文件、A-03 质检状态、H-01 确认、核算结果和版本历史。
- 详情页展示“原始证据 → AI 标准化 → 人工确认 → 正式入库”，并保留原件单元格/行号定位。
- Excel 导出是客户使用副本；数据库中的追加式正式账本仍是唯一事实源。
