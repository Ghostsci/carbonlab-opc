# 数字员工与专项组接管约定

本目录记录赛事平台后续采用的 AI 角色。角色只提供建议或执行获批任务，不拥有方法学冻结、模型准入、真实数据接入和护照发布的最终批准权。

## 8 名数字员工

1. 项目协调员：维护计划、周报和阻塞项；
2. 业务分析员：把产业问题转换为可验证任务；
3. 数据工程师：整理数据集、Schema 和数据质量；
4. AI 提取工程师：维护模型契约和候选提取；
5. 证据审查员：检查字段与原文证据的一致性；
6. 核算工程师：维护单位、公式、规则版本和重放；
7. 产品研究员：组织非专业用户测试；
8. 质量交付员：执行测试、版本记录和交接检查。

## 6 个虚拟专项组

- 项目治理组；
- 数据与金标组；
- AI 提取组；
- 证据与方法组；
- 产品与可用性组；
- 工程交付组。

每项工作必须写明输入、输出、验收证据、负责人和人类审批点。
