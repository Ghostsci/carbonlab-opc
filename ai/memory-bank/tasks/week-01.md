# 第 1 周任务单

## 本周唯一目标

冻结一个足够小、可独立判断对错的验证场景，而不是继续增加功能。

## 任务

1. 确认虚拟企业、装置、产品和报告期间；
2. 选择 6—10 个核心字段，定义类型、单位、证据要求和缺失处理；
3. 为每个字段建立独立标准答案；
4. 明确 Candidate/Holdout/Adversarial 的隔离规则；
5. 记录方法学、数据和模型需要的人类审批点；
6. 在赛事平台提交本周记录和相关 Git 提交链接。

## 完成定义

- 字段不再随意增删；
- 标准答案不由被测模型生成；
- 每个字段都有可验证证据；
- 所有待定项写明“待人类确认”；
- G1 通过前不得开始正式模型排名。
